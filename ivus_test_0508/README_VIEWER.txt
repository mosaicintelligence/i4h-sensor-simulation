ShowCase Exported Study README File
 
This file provides information about the CD/DVD study viewer
software provided on this disk.

** Instructions for using the CD/DVD Study Viewer ***********


- To run the viewer, first wait to see if the viewer comes up automatically. If it does not
you will need to double-click on the "Show_Studies" application on the CD.
 
- A directory of the studies on the CD should appear in the ShowCase CD Viewer application.
- Double-click on a study, or select the study and click the 'Show' button to display the 
   images in the study.
- You can double-click on an image to view it at full resolution.
- To play a clip, right-click on the image or click on the play arrow below the image. 
- Double-click on an image to access brightness & contrast adjustments, 
   or to margin a clip or set clip playback speeds.
- Select File->Exit to exit the ShowCase Viewer.


The viewer has menu items and features that are permanently 'disabled' because
the viewer is a read-only version of the ShowCase product sold by
Trillium Technology, Inc. (available on the web at www.TrilTech.com).


If you have questions about the ShowCase product, you can contact Trillium
Technology via email at Support@TrilTech.com.



** System Requirements for ShowCase CD/DVD Viewer ***************


The ShowCase Viewer provided on this CD runs on Windows XP/Vista/7 operating systems.


The minimum screen size setting is 1024 x 768. IVUS studies must be shown at 1024 x 768 or higher.


Performance will depend on your CD/DVD reader, processor speed, free memory and free disk space.


For viewing studies with multi-frame images (clips) we recommend a minimum of-
1 GB RAM, 2 GB free disk space, Pentium IV processor


Monitor settings supported: 24 bit color, and 32 bit color. 
16-bit color is not supported and not recommended for viewing medical images.
